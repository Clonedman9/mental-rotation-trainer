# 心理旋转训练器 · Mental Rotation Trainer

单文件网页版的心理旋转训练与测量工具。原生 JavaScript + Canvas，**无框架、无构建、无外部依赖、可完全离线运行**。

## 这是什么

经典的 Shepard & Metzler (1971) 心理旋转范式：屏幕左侧给出一个物体，右侧给出它旋转某个角度后的样子——或者旋转后再做镜像的样子。你需要在脑中把它转过来，判断两者是否**完全相同**。

本项目的重点不只是"玩"，而是让"我到底有没有变快"这件事**可以用数字回答**：

- 反应时随角度差的斜率 → 旋转速度（°/s）
- 每个速度都带 95% 置信区间，差异没超出误差就不算变快
- 按周聚合，跨周比较才有意义
- 数据本地存储，可导出 CSV / JSON

## 功能

**图形**
- 3D 立体：随机多立方体（polycube），保证手性 + 无旋转对称
- 2D 平面：随机多格拼块（polyomino），排除 90°/180°/270° 对称与镜像可重合
- 4–10 块 / 格可调

**训练**
- 每组题数 20 / 40 / 60 / 不限
- 自适应难度（可关闭，关闭后角度均匀抽样）
- 分数、连击、即时反馈、震动

**测量**
- 旋转速度 = 1000 ÷ 斜率（ms/度），附 95% 置信区间（t 分布）
- 拟合优度 R²、截距、反应时变异系数
- 分角度区间统计
- 按 ISO 周聚合的趋势图，带误差棒与首周基线
- 水平对照：按参考分布估算所处百分位

**数据**
- 每次作答落盘，切后台/关闭自动保存
- 导出 JSON（完整结构）、CSV（逐试次）
- 统计口径隔离：2D / 3D、不同块数不合并计算

## 指标口径

**旋转速度**

```
RT = a + b · θ        →    speed = 1000 / b   (°/s)
```

`b` 是每增加 1° 所需的毫秒数。斜率标准误由残差方差算出，置信区间在斜率空间求端点后再取倒数，避免非线性变换失真。

**参考分布**

水平对照使用对数正态分布，中位数 3D 取 50 °/s、2D 取 60 °/s，几何标准差约 1.45。依据是经典研究中约 20 ms/度的典型斜率。**这是用于自我定位的近似刻度，不是实测常模**，个体差异极大。

**剔除规则**

反应时 < 250 ms 或 > 10 s 的试次不参与拟合；速度估计需要至少 12 次正确作答。

## 本地运行

直接双击 `index.html`。

要装成手机 App（PWA），需要一个 http(s) 环境：

```bash
python3 -m http.server 8000
# 手机访问 http://<电脑局域网IP>:8000
# 浏览器菜单 → 添加到主屏幕
```

或部署到任意静态托管（GitHub Pages / Vercel / Cloudflare Pages），纯静态、无需构建。

## 技术说明

- 3D 渲染：自写正交/弱透视投影 + 背面剔除 + 画家算法排序，纯 Canvas 2D，无 WebGL、无 Three.js
- 图形生成：随机生长 + 群论校验（24 阶立方体旋转群 / 4 阶平面旋转群），确保题目在数学上无歧义
- 单文件：所有 CSS/JS 内联，零网络请求
